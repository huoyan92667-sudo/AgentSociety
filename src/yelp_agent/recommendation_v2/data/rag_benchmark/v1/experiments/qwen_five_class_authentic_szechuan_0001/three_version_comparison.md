# 三种评论证据判断方法真实对比

问题：费城唐人街中心300米以内有川菜馆吗？川菜味道地道正宗吗？

三种方法使用完全相同的 90 条评论片段。正确答案按证据是否真实出现在命中片段中重新计算：以GLM保存的逐字证据位置为准；证据不在命中片段中时，片段标签记为irrelevant。

## 总体结果

| 方法 | 五类完全正确 | 相关证据查准率 | 相关证据查全率 |

| 第二版：交叉判断模型 | 37/90 (41.11%) | 96.43% | 44.26% |
| 第三版：Qwen五分类 | 53/90 (58.89%) | 85.07% | 93.44% |
