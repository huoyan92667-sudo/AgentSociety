# Mission: 用 LoRA 训练餐厅评论判断小模型

## Why
掌握一条可实际运行的训练路线，让本地小模型读取一条完整餐厅评论后，稳定输出评论真正提到的14种软特征、五级程度、条件和菜品对象，从而低成本处理49.9万条评论并生成可追溯的商家画像。

## Success looks like
- 能解释普通微调、LoRA 和四位加载 LoRA 的差别以及为什么当前机器适合最后一种
- 能把强模型生成的标准答案整理成合法、无商家泄漏的训练数据
- 能在8GB显存上完成一次可恢复、可复现的小模型训练
- 能用按商家隔离的测试集判断小模型是否真的学会相关性、五级程度和条件提取

## Constraints
- 本机显卡约8GB，不能假设能够完整训练大模型全部参数
- 训练主数据必须来自完整原始评论，不能拿星级或相近程度代替文字判断
- 输出结构固定，不使用臆造的置信度，也不让小模型直接生成商家总分
- 讲解使用直白中文，必要术语必须紧接着解释

## Out of scope
- 现在不训练最终模型
- 现在不决定具体基础模型型号
- 现在不实现商家14项分数聚合和正式推荐排序
